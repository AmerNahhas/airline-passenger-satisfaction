# Airline Passenger Satisfaction Analysis ✈️

A data analysis project exploring factors that drive airline passenger satisfaction and dissatisfaction using SQL, Excel, and Tableau.

## Business Questions
- Which factors contribute most to customer satisfaction?
- Does flight distance affect customer preferences?
- What is the profile of a returning airline passenger?

## Key Findings
- Arrival delay has the highest impact on customer preferences (4%)
- In-flight WiFi and online boarding are top satisfaction drivers
- Personal travel type passengers are 90% dissatisfied
- Returning passengers are mostly middle-aged (53%) and evenly split by gender
- Business travelers show higher satisfaction than personal travelers

## Tools Used
- **SQL (BigQuery)** — correlation analysis, CASE statements, GROUP BY
- **Excel** — COUNTIF, COUNTIFS, nested IF functions, customer profiling
- **Tableau** — data visualization and dashboards

## SQL Concepts Used
- CORR() for correlation analysis
- CASE statements for categorizing flight distances
- GROUP BY for segmentation
